 Git e GitHub

Durante meus estudos, estou aprendendo a utilizar o **Git e o GitHub** para controlar versões dos projetos e trabalhar de forma colaborativa.

 Commits

Utilizo commits para registrar as alterações realizadas no projeto.

Exemplo:

bash
git add .
git commit -m "Adiciona nova funcionalidade"


Os commits ajudam a manter um histórico organizado do desenvolvimento.



 Branches

As branches permitem desenvolver funcionalidades separadamente sem alterar diretamente a versão principal do projeto.

Exemplo:

```bash
git branch nova-funcionalidade
git checkout nova-funcionalidade
```

Também posso criar uma branch diretamente com:

```bash
git checkout -b nova-funcionalidade
```

---

 Push

O `push` é utilizado para enviar os commits do computador para o repositório no GitHub.

```bash
git push origin minha-branch
```

---

 Merge

O `merge` permite juntar as alterações realizadas em uma branch com outra.

Exemplo:

```bash
git checkout main
git merge minha-branch
```

Esse processo é importante principalmente em projetos colaborativos.
